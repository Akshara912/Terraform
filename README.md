# Terraform AWS Networking Project

## Overview
This project provisions AWS infrastructure using Terraform.

## Objective
To create reusable cloud infrastructure with Infrastructure as Code.

## Tech Stack
- Terraform
- AWS
- Linux
- GitHub

## Resources Created
- VPC
- Subnet
- Security Group
- Inbound and outbound rules

## Files
- provider.tf
- main.tf
- variables.tf
- outputs.tf
- terraform.tfvars


## How to Run
terraform init
terraform plan
terraform apply
